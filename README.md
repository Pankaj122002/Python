# Machine Learning Projects Repository

A comprehensive collection of machine learning projects implementing various predictive models and algorithms using Python and Jupyter Notebooks.

## 📋 Overview

This repository contains multiple machine learning projects that demonstrate the application of different algorithms for classification, regression, and recommendation systems. Each project is implemented as a Jupyter Notebook with complete exploratory data analysis (EDA), model training, and evaluation.

## 🎯 Projects

### Prediction Models

| Project | Type | Description |
|---------|------|-------------|
| **Admission Prediction** | Classification | Predicts university admission chances based on student metrics |
| **Big Sales Prediction** | Regression | Forecasts sales figures using historical data and features |
| **Cancer Prediction** | Classification | Identifies cancer risk based on health indicators |
| **Credit Card Default Prediction** | Classification | Predicts credit card default probability for risk assessment |
| **Diabetes Prediction** | Classification | Predicts diabetes risk based on health condition metrics |
| **Fish Weight Prediction** | Regression | Estimates fish weight from physical characteristics |
| **Wine Quality Prediction** | Regression | Predicts wine quality scores from chemical properties |

### Recommendation & Classification

| Project | Type | Description |
|---------|------|-------------|
| **Movie Recommendation System** | Recommendation | Suggests movies based on user preferences and ratings |
| **Women Cloth Reviews Prediction** | Text Classification | Classifies clothing reviews using Multinomial Naive Bayes |
| **Purchase Prediction & Micronumerosity** | Classification | Analyzes purchase patterns and customer behavior |

## 💻 Technologies & Libraries

- **Python 3.x**
- **Jupyter Notebook**
- **scikit-learn** - Machine learning algorithms
- **pandas** - Data manipulation and analysis
- **NumPy** - Numerical computing
- **Matplotlib & Seaborn** - Data visualization
- **TensorFlow/Keras** - Deep learning (where applicable)
